Kanso Labs makes a design system drawn on the web and on iOS and Android, packaging for Home Assistant, and the shared CI that keeps all of it current. These pages are the guides: how to install each project, set it up and use it day to day.

<CardGroup cols={2}>
  <Card title="Kanso UI" icon="palette" href="/kanso-ui/web/introduction">
    A React component library on React Aria Components, styled with StyleX, following Material Design.
  </Card>
  <Card title="Kanso UI for React Native" icon="mobile" href="/kanso-ui/react-native/introduction">
    The same components, tokens and theming, drawn with React Native's own primitives.
  </Card>
  <Card title="Style Dictionary plugin" icon="plug" href="/style-dictionary/introduction">
    Compiles Style Dictionary design tokens ahead of Vite, Rolldown, Rollup, Rspack or Webpack.
  </Card>
  <Card title="Home Assistant" icon="house-signal" href="/home-assistant/applications/introduction">
    Applications for the arr stack, Plex, n8n and more, and a live robot vacuum map.
  </Card>
</CardGroup>
