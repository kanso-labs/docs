## Design system

One set of design tokens, drawn on the web and on iOS and Android.

<CardGroup cols={1}>
  <Card title="Kanso UI" icon="react" href="/kanso-ui/web/introduction">
    A React component library on React Aria Components, styled with StyleX. Every token carries a default, light and dark, so a component renders correctly the moment it is imported.

    [Storybook](https://kanso-ui.kansolabs.org/) · [GitHub](https://github.com/kanso-labs/kanso-ui) · [npm](https://www.npmjs.com/package/@kanso-labs/kanso-ui)
  </Card>
  <Card title="Kanso UI for React Native" icon="mobile" href="/kanso-ui/react-native/introduction">
    Kanso UI's Material Design components for React Native, on the same design tokens and theming as kanso-ui, so one theme object serves a web app and a native app alike.

    [Storybook](https://react-native-kanso-ui.kansolabs.org/) · [GitHub](https://github.com/kanso-labs/react-native-kanso-ui) · [npm](https://www.npmjs.com/package/@kanso-labs/react-native-kanso-ui)
  </Card>
  <Card title="Kanso UI Core" icon="cube" href="/kanso-ui/core/introduction">
    The design data both libraries share: the design tokens, the glyph paths and the demo schemes. Neither library hands it on to an app.

    [GitHub](https://github.com/kanso-labs/kanso-ui-core) · [npm](https://www.npmjs.com/package/@kanso-labs/kanso-ui-core)
  </Card>
  <Card title="Unplugin Style Dictionary" icon="plug" href="/style-dictionary/introduction">
    Compiles Style Dictionary design tokens ahead of your bundler. One implementation targets Vite, Rolldown, Rollup, Rspack and Webpack, with watching and HMR under Vite.

    [GitHub](https://github.com/kanso-labs/unplugin-style-dictionary) · [npm](https://www.npmjs.com/package/@kanso-labs/unplugin-style-dictionary)
  </Card>
</CardGroup>

## Apps

Small everyday tools, built on Kanso UI.

<Card title="Daily" icon="sun" href="https://daily.kanso-labs-org.workers.dev/">
  Small everyday tools under one calm shell: expenses shared across groups, each keeping its own currency and settled up without Daily ever moving money, and a focus timer. Installable, offline-ready, in English and Brazilian Portuguese. Its source is private.
</Card>

## Home Assistant

Applications and an integration for Home Assistant.

<CardGroup cols={1}>
  <Card title="Home Assistant Applications" icon="house-signal" href="/home-assistant/applications/introduction">
    Home Assistant applications for the arr stack, Plex, qBittorrent, NZBGet, Seerr and n8n. aarch64 and amd64, kept current automatically.

    [Catalogue](https://home-assistant.kansolabs.org/) · [GitHub](https://github.com/kanso-labs/home-assistant-applications)
  </Card>
  <Card title="Robot Vacuum Map" icon="robot" href="/home-assistant/robot-vacuum-map/introduction">
    A Home Assistant integration, installed through HACS, that draws live maps of Xiaomi, Roborock, Dreame, Viomi, Roidmi and iJai robot vacuums from Xiaomi's cloud, with no rooting. Built on Piotr Machowski's Xiaomi Cloud Map Extractor.

    [GitHub](https://github.com/kanso-labs/home-assistant-robot-vacuum-map)
  </Card>
</CardGroup>
