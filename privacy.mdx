This site uses Google Analytics for anonymous usage statistics: it counts visits, so Kanso Labs can see which pages are read. There are no accounts here and no ads. Nothing that names you is collected; Google Analytics tells one browser from another by a random ID, not by who is using it.

## What is recorded

The pages you open and the page that led you here; reaching the end of a page; clicks on links that leave the site; and files you download. With each, Google Analytics records your browser, device, language and approximate location, which it derives from your IP address without storing the address. No user ID is set, and nothing you type is sent.

Google signals and every advertising feature are off, and the site tells Google that consent for ads is denied, for every visitor.

## Cookies

While analytics is on, Google Analytics sets two cookies on this site alone, `_ga` and one beginning `_ga_`, to tell a returning browser from a new one. Each Kanso Labs site keeps its own.

Your choice is shared: it applies to every Kanso Labs site under kansolabs.org, so you answer once. It is kept for 13 months in a cookie on kansolabs.org, `kl_consent`, which only Kanso Labs sites read, and goes nowhere else.

## How long it is kept

Google Analytics deletes the records of each visit after 14 months. The totals in its reports, such as how many times a page was read in a month, are kept.

## Your choice

In the European Economic Area, the United Kingdom and Switzerland, the site asks before it loads Google Analytics, and nothing is sent until you allow it. A static site cannot see where you are, so it goes by your browser's time zone, and asks whenever the zone leaves it unsure. Elsewhere analytics is on until you turn it off. If your browser keeps the time of another place while you are in one of those, Google still keeps its cookies off for you, by your IP address, though it may receive the visit without them; turning analytics off here stops that too.

{/* The switch. analytics.js, at the root of this repository, loads the shared
    https://kansolabs.org/analytics.js, which counts visits, draws the banner
    and leaves window.kansoAnalytics for this to
    read and change. It may load after the page, so this listens for it. */}

export const AnalyticsChoice = () => {
  const [state, setState] = useState(null)

  useEffect(() => {
    const update = () => {
      const analytics = window.kansoAnalytics
      if (analytics) setState({ analytics, status: analytics.status() })
    }
    update()
    window.addEventListener('kanso-analytics', update)
    return () => window.removeEventListener('kanso-analytics', update)
  }, [])

  if (!state) {
    return <p>The setting for this browser appears here once the page has loaded.</p>
  }

  const on = state.status === 'granted'

  return (
    <div style={{ display: 'flex', flexDirection: 'column', alignItems: 'flex-start', gap: '12px' }}>
      <p style={{ margin: 0 }}>
        {on ? 'Analytics is on for Kanso Labs sites in this browser.' : 'Analytics is off for Kanso Labs sites in this browser.'}
      </p>
      <button
        className="rounded-full border border-gray-400 px-4 py-2 text-sm font-medium dark:border-gray-500"
        onClick={on ? state.analytics.deny : state.analytics.grant}
        type="button"
      >
        {on ? 'Turn it off' : 'Turn it on'}
      </button>
    </div>
  )
}
