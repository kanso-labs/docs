Kanso UI is a React component library built on [React Aria Components](https://react-aria.adobe.com) and styled with [StyleX](https://stylexjs.com). Its design tokens come from a single [W3C Design Tokens (DTCG)](https://design-tokens.github.io/community-group/format/) file, compiled with [Style Dictionary](https://styledictionary.com), and every component follows its Material Design spec page.

Every token carries a default, light and dark, so a component renders correctly the moment it is imported.

```bash
npm install @kanso-labs/kanso-ui
```

```tsx
import { Button } from '@kanso-labs/kanso-ui'

export function Example() {
  return <Button>Click me</Button>
}
```

## What the package includes

- **Components** built on React Aria Components, each drawn to its Material Design spec: sizes, shapes, type and colour roles, in every state the spec lists.
- **The React Aria utilities** an app needs around them, re-exported so you never install a second copy. See [React Aria and dates](/kanso-ui/web/react-aria).
- **Layout primitives**: `Container`, `Stack`, `Feed`, `ListDetail` and `SupportingPane`. See [Layout](/kanso-ui/web/layout).
- **Design tokens** as `--kui-*` custom properties, published as `tokens.css` and as the DTCG source `tokens.json`.

The package ships no icons and no typefaces; those come from your app. See [Icons](/kanso-ui/web/icons).
