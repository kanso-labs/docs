`ThemeScope` themes everything inside it, and takes the same props as the web library's:

<ParamField path="theme" type="KuiTheme">
  A map of `--kui-*` properties to CSS values. A nested scope's map applies over its parent's.
</ParamField>

<ParamField path="scheme" type="'light' | 'dark'">
  Pins the scope to light or dark and paints its surface. Left unset, the scheme follows the scope around it, or the device's appearance at the root.
</ParamField>

```tsx
import { type KuiTheme, ThemeScope } from '@kanso-labs/react-native-kanso-ui'

// The same object a web app hands kanso-ui's ThemeScope.
const brand: KuiTheme = {
  '--kui-color-primary': '#006a6a',
  '--kui-radius-md': '16px',
}

export default function App() {
  return (
    <ThemeScope style={{ flex: 1 }} theme={brand}>
      <Screen />
    </ThemeScope>
  )
}
```

To build a full theme from one colour, use the [Material Theme Builder](/kanso-ui/web/theming/material-theme-builder) recipe: its output is a `KuiTheme` both libraries take.

## Reading tokens

`useTheme()` reads the tokens in the values React Native styles take, under the keys of the web library's token modules:

| Web | React Native |
| --- | --- |
| `var(--kui-color-primary)` | `useTheme().colors.primary` |
| `12px` | `12` (dp) |
| `100ms` | `100` (ms) |
| `cubic-bezier(…)` | the four points `Easing.bezier()` takes |

```tsx
import { useTheme } from '@kanso-labs/react-native-kanso-ui'
import { View } from 'react-native'

function Swatch() {
  const { colors } = useTheme()
  return <View style={{ backgroundColor: colors.primaryContainer, height: 48 }} />
}
```

<Note>
  A value React Native cannot evaluate, such as `calc()` or `color-mix()`, keeps its property at the library's default, and a development build names it in a warning.
</Note>

What the library draws above the screen follows the scope it was opened in rather than the root's, so a sheet opened inside a branded scope keeps that brand.

## Fonts

Neither package ships a font. On iOS and Android a type role draws in the first family its token names when the app has registered that family with [expo-font](https://docs.expo.dev/versions/latest/sdk/font/) under that name, and in the system font otherwise.

```tsx
import { useFonts } from 'expo-font'

const [loaded] = useFonts({
  'Roboto Flex': require('./assets/RobotoFlex.ttf'),
  'Roboto Serif': require('./assets/RobotoSerif.ttf'),
})
```

Under React Native Web the token's whole family list goes to CSS, as it does on the web.
