Robot Vacuum Map is a Home Assistant integration, installed through HACS, that draws a live map of your robot vacuum from Xiaomi's cloud. It reads Xiaomi, Roborock, Dreame, Viomi, Roidmi and iJai vacuums, and needs no rooting.

It is a kanso-labs copy of Piotr Machowski's [Xiaomi Cloud Map Extractor](https://github.com/PiotrMachowski/Home-Assistant-custom-components-Xiaomi-Cloud-Map-Extractor), with a domain of its own, `robot_vacuum_map`, so the two can be installed side by side. The copy exists so that the Xiaomi Robot Vacuum S20+ is drawn live.
